# ReviewIQ

ReviewIQ is an intelligent product feedback analysis system using NLP.

## Objective

ReviewIQ analyzes e-commerce product reviews using Aspect-Based Sentiment Analysis (ABSA).

## Main Features

- Review dataset upload
- Text preprocessing
- Product aspect extraction
- Aspect-level sentiment analysis
- Positive / Negative / Neutral classification
- Feedback aggregation
- Product feedback summarization
- PostgreSQL storage
- Interactive dashboard

## Technology Stack

- Python
- FastAPI
- Pandas
- NumPy
- spaCy
- Hugging Face Transformers
- RoBERTa
- Scikit-learn
- PostgreSQL
